# 🍗 Kirby After The Food
  This is my very first game project. A very simple and straightforward game in which you take control of Kirby,  
  a gluttonous little pink ball who’s on the hunt for his meal!

## 🚦 Running The Project
  1- Open this google drive ---> [LINK](https://drive.google.com/file/d/1b2fHdgqmDVugrexNL_eiJHlSorpscw4y/view?usp=drive_link) <---  
  2- Download and extract the .zip file.  
  3- Search for the .exe file inside the folder.  
  4- Run it and have fun!
